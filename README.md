# WorkHealth

> Персональная система для планирования, выполнения и отслеживания тренировок с собственным весом.

WorkHealth помогает превратить тренировки в последовательный процесс: от определения текущего уровня до выполнения запланированных подходов и отслеживания прогресса.

## ✦ Возможности

### 🔐 Авторизация

* Регистрация и вход в аккаунт
* Выход из аккаунта
* Восстановление пароля через email
* Безопасное управление пользовательскими сессиями

### 🏋️ Тренировки

* Персональные тренировочные недели
* Автоматическое формирование тренировок
* Планирование тренировочных дней
* Отслеживание каждого подхода
* Фиксация фактического количества повторений
* Завершение тренировок
* Пропуск тренировок
* Отмена тренировок

### 📈 Прогресс

* Определение максимального количества повторений для каждого упражнения
* История тренировок
* Отслеживание выполнения тренировочного плана
* Статистика тренировочной активности

### ⚙️ Настройки

* Выбор темы оформления
* Звуковые уведомления
* Настройка уведомлений
* Настройка часового пояса пользователя

## 🧩 Архитектура

WorkHealth разделяет приложение на несколько логических уровней:

* **UI-компоненты** отвечают за отображение интерфейса и взаимодействие с пользователем.
* **Клиентская логика** управляет состоянием и поведением интерактивных элементов.
* **Server logic** содержит серверные операции и бизнес-логику.
* **API** предоставляет необходимые endpoints для взаимодействия с клиентской частью.
* **Prisma** обеспечивает типизированную работу с PostgreSQL.
* **Providers** используются для глобальных возможностей приложения, таких как тема оформления.

Такое разделение позволяет изолировать ответственность различных частей приложения и упрощает дальнейшее развитие проекта.

## 🗃️ Данные

Основные данные приложения хранятся в PostgreSQL.

Prisma используется как ORM и является основным слоем взаимодействия серверной части с базой данных.

Схема базы данных находится в:

```text
prisma/schema.prisma
```

## 🔑 Основные сущности

В приложении используются сущности, связанные с:

* пользователями;
* тренировочными планами;
* тренировочными неделями;
* тренировочными днями;
* упражнениями;
* подходами;
* результатами тренировок;
* максимальными результатами;

Конкретная структура и связи между сущностями определяются в `prisma/schema.prisma`.

## 📊 Жизненный цикл тренировки

Основной сценарий работы пользователя выглядит следующим образом:

```text
Определение уровня
        ↓
Формирование тренировочного плана
        ↓
Создание тренировочных дней
        ↓
Выполнение тренировки
        ↓
Фиксация результатов подходов
        ↓
Завершение тренировки
        ↓
Сохранение истории
        ↓
Анализ прогресса
        ↓
Следующий тренировочный цикл
```

Таким образом, WorkHealth связывает планирование, выполнение и анализ тренировок в единый цикл.

## 🚀 Запуск проекта

Установите зависимости:

```bash
npm install
```

Создайте файл `.env` и укажите необходимые переменные окружения, включая подключение к PostgreSQL и настройки email-сервиса.

После настройки базы данных примените Prisma-схему:

```bash
npx prisma generate
npx prisma migrate dev
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3000
```

## 🏗️ Production

Сборка проекта:

```bash
npm run build
```

Запуск production-версии:

```bash
npm start
```

## 📌 Цель проекта

WorkHealth создаётся как полноценная персональная система управления тренировочным процессом.

Основная идея проекта — не просто записывать результаты тренировок, а выстроить последовательный процесс:

> **оценить текущий уровень → получить план → выполнить тренировку → сохранить результат → увидеть прогресс → продолжить тренировочный цикл.**

Это позволяет постепенно превращать разрозненные тренировки в структурированную систему с накоплением истории и измеримым прогрессом.
